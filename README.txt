Everly — Free Couple's Wedding Website Template by uiCookies

CONCEPT
  Everly is an editorial, single-page wedding invitation site for a modern
  couple. It leads with a full-bleed romantic hero and a live countdown, then
  walks guests through an alternating story timeline, the day's ceremony and
  reception details, a photo gallery, the wedding party, a working RSVP form,
  a gift registry, and travel & accommodation — all on one self-contained page.
  Built on Bootstrap 5 with vanilla JavaScript (no jQuery) and inline SVG icons,
  so it deploys cleanly even on strict-CSP static hosts.

FONT PAIRING

  Accent  : Pinyon Script       (calligraphy for the couple's names & eyebrows)
